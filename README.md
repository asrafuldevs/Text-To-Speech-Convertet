# Text-To-Speech-Convertet

A simple web app that converts written text into speech using the browser's built-in Web Speech API.

## Live Demo

https://asrafuldevs.github.io/Text-To-Speech-Convertet/

## Features

- Convert any typed text to speech
- Choose from available system voices
- Clean and responsive interface
- Runs directly in the browser (no backend required)

## Technologies Used

- HTML5
- CSS3
- JavaScript (Web Speech API)

## How It Works

1. Enter text in the textarea.
2. Select a voice from the dropdown list.
3. Click **Listen** to play speech output.

## Run Locally

1. Clone this repository.
2. Open `index.html` in your browser.
